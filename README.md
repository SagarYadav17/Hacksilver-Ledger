# Hacksilver Ledger

Offline-first personal finance app for Android and iOS. The repository is a
single Expo/React Native project; SQLite is the local source of truth and
PocketBase is optional self-hosted cloud storage.

## Quick start

```bash
bun install
bun run start
```

Quality checks:

```bash
bun run typecheck
bun run lint
bun run format:check
bun test
```

Native development:

```bash
bun run android
bun run ios
bun run web
```

The `android/` and `ios/` directories are generated by Expo prebuild and are
ignored by Git. Use a development build for SQLite, SecureStore,
notifications, and background-task behavior.

## Product capabilities

- Accounts, income, expenses, transfers, categories, recurring transactions,
  loans, EMI-linked payments, and local JSON backup/restore.
- Light, dark, and system themes; currency selection; optional PIN lock and
  balance hiding.
- Transaction search, type/date filters, details, edit, and delete.
- Analytics for income, expenses, savings rate, trends, and category spend.
- Optional PocketBase login and two-way sync with tombstones and conflict
  history. Sessions use secure storage and remote records are user-scoped.

## Repository layout

- `app/`: Expo Router screens and navigation.
- `components/`: shared UI and security components.
- `data/`: SQLite schema/repository, hooks, sync, backup, notifications, and
  background work.
- `domain/`: storage-independent ledger types.
- `lib/`: formatting and visual theme primitives.
- `store/`: persisted local preferences.
- `test/`: Bun unit and repository tests.
- `docs/`: PocketBase and product implementation notes.
- `design_handoff_hacksilver_redesign/`: local design references.

This app is still in development. Local schema changes are intentionally
destructive while the product is pre-release: clear app data or reinstall
before testing a new build, and do not rely on development data surviving an
update.

For PocketBase setup and collection rules, see
[POCKETBASE_SETUP.md](POCKETBASE_SETUP.md).
